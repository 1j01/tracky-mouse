Companion Software

Tracky Mouse pairs great with these other assistive technologies.

On-Screen Keyboards

  • Dasher (Windows/Linux, Free & Open Source) - I highly recommend trying this one out. It may look intimidating at first, but mainly you only need to memorize the order of the alphabet (in a spatial way) to become proficient with it.
  • OptiKey Pro (Windows, Free & Open Source) - Very solid. Everything you'd expect from an on-screen keyboard, plus tools for triggering different types of clicks and scrolls.
    ℹ️ If you want to use facial gestures to click on the keyboard, first right click on the keyboard, go to "Management Console (Settings)", then go to the "Pointing & Selecting" tab, and set "Key selection source" to "Mouse button".
    ⚠️ Note that some of the features may conflict and cause Tracky Mouse to stop moving the mouse. It can also stop working when simply launching OptiKey. (issue #109)

Voice Control

I don't have any specific recommendations for voice control software at the moment, but note that any scriptable voice control software should be able to start/stop Tracky Mouse using the command line interface.

Drawing

JS Paint can be configured with large buttons for use with Tracky Mouse.

👉 Open JS Paint with enlarged UI

JS Paint includes built-in Tracky Mouse support:

  • Enable Extras > Head Tracker to try the Tracky Mouse UI inside JS Paint.
  • Enable Extras > Dwell Clicker to use dwell clicking that understands when you're drawing.

When using Tracky Mouse with JS Paint, you can either use the Tracky Mouse desktop app to move the cursor and click with facial gestures, or use JS Paint's built-in head tracker and dwell clicker.

Also try View > Fullscreen and Extras > Speech Recognition.
